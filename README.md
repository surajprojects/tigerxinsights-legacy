# Tiger Insights Legacy

Tiger Insights Legacy is a personal portfolio website built using pure HTML, CSS, and JavaScript. This legacy project serves as a central hub to showcase projects, share social media links, and establish an online presence.

Deployed using GitHub Pages, it represents an early stage of my development journey and reflects a strong foundation in core web technologies.

## Features

- Clean and responsive portfolio design
- Showcases multiple projects with direct links
- Social media integration (LinkedIn, GitHub, etc.)
- Fully static website (fast and lightweight)
- Deployed using GitHub Pages
- No dependencies or frameworks

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla JS)

## Deployment

This web app is deployed using [Github Pages](https://github.com) by Tiger. You can access the live version here [Tiger Insights Legacy](https://surajprojects.github.io/tigerxinsights-legacy)

## Installation & Setup

1. Clone the repository
2. Navigate to the folder
3. Simply open index.html in your browser
